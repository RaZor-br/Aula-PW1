Dicionário de Dados

Entidade: Sala

Tabela Atributo Tipo Tamanho Restrições Descrição
Sala nome Varchar 50 Chave Primária, Not Null Nome ou identificador único da sala de exibição
capacidade Integer - Not Null Capacidade máxima de assentos da sala

Entidade: Filme

Tabela Atributo Tipo Tamanho Restrições Descrição
Filme codFilme Integer - Chave Primária, Not Null Código de identificação do filme
diretor Varchar 100 Not Null Nome do diretor do filme
nomePortugues Varchar 100 Not Null Título do filme traduzido para o português
nomeOriginal Varchar 100 Not Null Título original do filme
tipo Varchar 30 Not Null Gênero ou tipo do filme (ex: Ação, Drama)
sinopse Varchar 500 Null Breve resumo da história do filme
ano Integer 4 Not Null Ano de lançamento do filme

Entidade: Sessão

Tabela Atributo Tipo Tamanho Restrições Descrição
Sessão codHorario Integer - Chave Estrangeira, Not Null Referência ao horário da sessão (horário.codHorario)
codFilme Integer - Chave Estrangeira, Not Null Referência ao filme exibido (filme.codFilme)
nome Varchar 50 Chave Estrangeira, Not Null Referência à sala da exibição (sala.nome)
data Date - Not Null Data em que a sessão será realizada

Entidade: Horário

Tabela Atributo Tipo Tamanho Restrições Descrição
Horário codHorario Integer - Chave Primária, Not Null Código identificador do horário
horario Time - Not Null Hora exata do início

Entidade: Premiação

Tabela Atributo Tipo Tamanho Restrições Descrição
Premiação codPremiação Integer - Chave Primária, Not Null Código de identificação da premiação
codFilme Integer - Chave Estrangeira, Not Null Referência ao filme premiado (filme.codFilme)
descrPremiação Varchar 150 Not Null Nome ou categoria do prêmio recebido
ano Integer 4 Not Null Ano de recebimento do prêmio

Entidade: Trabalha

Tabela Atributo Tipo Tamanho Restrições Descrição
Trabalha codEscala Integer - Chave Primária, Not Null Código identificador da escala de trabalho
codHorario Integer - Chave Estrangeira, Not Null Referência ao horário de trabalho (horário.codHorario)
carteiraTrabalho Varchar 20 Chave Estrangeira, Not Null Referência ao funcionário alocado (funcionario.carteiraTrabalho)
função Varchar 50 Not Null Cargo ou função desempenhada no turno

Entidade: Funcionário

Tabela Atributo Tipo Tamanho Restrições Descrição
Funcionário carteiraTrabalho Varchar 20 Chave Primária, Not Null Número da Carteira de Trabalho e Previdência Social (CTPS)
nome Varchar 100 Not Null Nome completo do funcionário
salario Decimal 10 Not Null Valor da remuneração mensal
dataAdmissão Date - Not Null Data de contratação do funcionário
